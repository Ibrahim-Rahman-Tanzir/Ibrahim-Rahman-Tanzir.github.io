# Ibrahim Rahman — Personal Portfolio

A responsive personal portfolio inspired by the supplied lavender-and-purple reference layout. Built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Features
- Light lavender background and centered white rounded portfolio surface
- Purple accents, compact navigation, hero portrait illustration, and soft wave styling
- About, skills, qualification, services, portfolio, approach, and contact sections
- Responsive mobile navigation
- Dark/light theme toggle
- Contact form template (add your email in `assets/js/script.js` to enable `mailto`)
- No framework, build step, backend, or paid hosting required

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a GitHub repository (for example `ibrahim-rahman-portfolio`).
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the website.

## Before publishing
- Verify the GitHub and LinkedIn URLs in `index.html`.
- Replace the Q-SHIELD button's GitHub profile URL with the exact public Q-SHIELD repository URL.
- Gmail is connected as `ibrahim.r.tanzir@gmail.com` in the contact links and contact form. The form opens an email draft in the visitor’s email app.
- The hero portrait is a CSS illustration placeholder. Replace it with your own image if desired.
- Skill bars are visual design elements, not verified proficiency scores.
